같은 숙소라도 로그인 상태와 접속 환경에 따라 표시되는 혜택을 비교하세요.

  1. 회원 대상 쿠폰

    로그인 전후에 동일한 숙박 상품을 열어 적용 가능 표시를 비교하세요. 회원 자격이 필요한 쿠폰이라면 로그인 후에도 객실·숙박일 조건을 다시 확인하세요.

    확인 시점

    판단 기준

  2. 앱 전용 표시가 있는 쿠폰

    앱 전용이라는 안내가 표시된 경우에는 앱에서 같은 숙소·객실·숙박일·인원을 다시 선택하세요. 웹 화면의 가격과 비교할 때 숙박 상품 자체가 달라지지 않았는지도 확인하세요.

    확인 시점
    앱에서 결제액이 표시될 때
    판단 기준
    동일한 숙박 상품의 최종 결제액

현재 제공되는 회원·앱 전용 쿠폰의 고정 할인율과 발급 여부는 확인되지 않았습니다. 혜택 표시가 없으면 적용 가능한 쿠폰이 있다고 가정하지 마세요.

쿠폰 적용 방법

할인 문구를 찾는 단계에서 멈추지 말고 예약 합계까지 확인하세요.

  1. 숙박 조건을 고르세요

    지역·숙박일·인원·객실 수를 먼저 정하세요. 검색 조건이 달라지면 비교하는 객실 요금도 달라집니다.

  2. 쿠폰 표시를 확인하세요

    숙소와 숙박 상품의 쿠폰 적용 대상 표시를 살피세요. 조식 포함 여부와 취소 규정이 같은 상품끼리 비교하세요.

  3. 로그인 후 결제액을 확인하세요

    회원 또는 앱 전용 조건이 표시된다면 해당 환경에서 결제 화면까지 진행하세요. 적용된 쿠폰 이름과 할인액을 확인하세요.

  4. 예약 합계를 다시 계산하세요

    예를 들어 객실 1개를 1박 120,000원에 2박 이용하면 할인 전 숙박 요금은 240,000원입니다. 이 금액에서 화면에 실제 표시된 쿠폰 할인액을 빼고, 별도 청구액이 있는지 확인하세요.

자주 확인하는 조건

쿠폰 자주 묻는 질문

쿠폰 표시와 실제 할인액이 다를 때 확인할 내용을 모았습니다.

  1. 라쿠텐트래블 쿠폰이 보이는데 왜 할인이 적용되지 않나요?

    선택한 객실이나 숙박 상품이 적용 대상에서 제외될 수 있습니다. 숙박일·인원·객실 수와 쿠폰 조건을 확인하고 결제 화면의 할인액을 다시 확인하세요.

  2. 라쿠텐트래블 쿠폰 두 개를 같이 쓸 수 있나요?

    일부 숙소 화면에서는 쿠폰 2개 적용 사례가 표시됩니다. 모든 예약에서 같은 조합이 허용되는 것은 아니므로 해당 예약의 결제 화면에서 적용된 쿠폰 목록을 확인하세요.

  3. 라쿠텐트래블 앱 쿠폰은 웹에서도 적용되나요?

    앱 전용으로 표시된 쿠폰은 웹 적용을 전제로 계산하지 마세요. 앱과 웹에서 동일한 숙박 상품의 최종 결제액을 각각 확인하세요.

  4. 회원 쿠폰은 로그인만 하면 자동으로 적용되나요?

    로그인만으로 적용을 확정할 수 없습니다. 회원 조건과 숙박 상품 조건을 충족한 뒤 결제 화면에 할인액이 표시되는지 확인하세요.

  5. 선착순 쿠폰은 발급하면 사용이 보장되나요?

    발급과 실제 사용 조건은 쿠폰마다 다를 수 있습니다. 예약을 확정하기 직전에 사용 가능 상태와 최종 할인액을 확인하세요.

  6. 쿠폰을 쓴 예약을 취소하면 다시 쓸 수 있나요?

    재사용 가능 여부는 해당 쿠폰의 조건에 따라 달라집니다. 취소 전 쿠폰 조건과 숙박 상품의 취소 수수료를 함께 확인하세요.
